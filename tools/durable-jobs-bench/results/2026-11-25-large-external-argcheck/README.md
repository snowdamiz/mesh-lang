## PostgreSQL and deployment findings

PG17.11 has no equivalent SQL-callable header-only object test. The stock `jsonb_typeof` and SQL `IS JSON OBJECT` both fully detoast JSONB before checking the root. JSONPath type tests also detoast the input before path execution. The executor evaluates the CHECK on the updated tuple after per-row BEFORE triggers and before the heap update. Rendering the claim context and other consumers can still materialize the argument. [PG17.11 catalog](https://github.com/postgres/postgres/blob/REL_17_11/src/include/catalog/pg_proc.dat) · [jsonb_typeof](https://github.com/postgres/postgres/blob/REL_17_11/src/backend/utils/adt/jsonb.c#L210-L223) · [IS JSON](https://github.com/postgres/postgres/blob/REL_17_11/src/backend/executor/execExprInterp.c#L3992-L4074) · [JSONPath](https://github.com/postgres/postgres/blob/REL_17_11/src/backend/utils/adt/jsonpath_exec.c#L430-L455) · [Update executor](https://github.com/postgres/postgres/blob/REL_17_11/src/backend/executor/nodeModifyTable.c#L1925-L1998)

The existing C helper copies the four-byte root header from ordinary and packed values with `memcpy`. Its strict SQL binding preserves SQL NULL, and the root object bit distinguishes objects from arrays, scalars, and JSON null. EXTERNAL uncompressed values can fetch the prefix alone. PGLZ can fetch a bounded compressed prefix. PG17.11 fetches the entire compressed external LZ4 value before partial decompression, and older LZ4 libraries fall back to full decompression. The screen applies to valid JSONB values. [Existing helper](../2026-11-23-large-storage-component/claim-memory/object.c) · [PG17.11 root flags](https://github.com/postgres/postgres/blob/REL_17_11/src/include/utils/jsonb.h#L178-L206) · [Slice dispatch](https://github.com/postgres/postgres/blob/REL_17_11/src/backend/access/common/detoast.c#L181-L312) · [LZ4 slice](https://github.com/postgres/postgres/blob/REL_17_11/src/backend/access/common/toast_compression.c#L198-L230)

Changing the CHECK changes the released producer layout fingerprint, even though the measured LARGE frames take the scalar path. Any later product qualification would have to preserve the exact bulk gate for eligible inputs and prove scalar fallback on drift or stock migration replay. A permissible exception would require the exact validated CHECK, its dependency on a protected C function, its owner and catalog identity, and readback of a pinned library from a trusted path. The other constraints, function definitions, ACLs, and RLS stay in the comparison. A validated constraint retains the stock name, error code, separate NOT NULL check, and per-row trigger ordering. A restore also needs the matching module and privileged installer. PostgreSQL dumps an extension's declaration and expects its files on the target server. The component did not qualify those deployment properties.
