## Controller commands

Use `python3 -B controller.py check` from this directory. The [recovery packet](controller-packet.json) requests one distinct 12-minute, build-free TIMING reservation behind the currently held bookings. The command verifies the original module's path, mode and exact hash as the actual unprivileged Linux caller under the existing host and lock fences. If the module is absent or fails identity, the command stops before staging. The packet authorizes no replacement SETUP. The two reversed off/sample/off rotations run once and stop on the first failed arm or reconciliation. The original SETUP, release, raw failure, packet and stage stay in place. Only the new stage and output paths belong to this reservation.

After a clean recovery release is exported under `evidence/native/controller-release.json`, run `python3 -B controller.py replay`. The native correction and any live plan attribution remain pending the sole controller's release.
