## Controller use

This is a separate zero-arm SETUP proposal. Once approved SDK bytes are available, the sole controller can use the existing queue to bind `request.json` and run the commands below in the canonical checkout. `check` reads the existing cache and frozen Git blobs. `stage` additionally requires the exact request in the controller inbox, the active supply SETUP window, the local dispatch lock and both native locks. It uses the existing host-key-pinned controller transport. The driver accepts an existing file for `--sdk`; acquisition and release stay with the controller.

```sh
d=tools/durable-jobs-bench/results/2026-11-25-slow-river-toolchain-supply
python3 -B "$d/controller.py" check
python3 -B "$d/controller.py" stage --sdk /approved/path/go1.26.4.linux-amd64.tar.gz
```

On native, the driver verifies the boot, kernel, CPU roster, benchmark disk, retained SLOW ELF, payload membership and digests, and official SDK bytes before unpacking. It checks the Linux AMD64 executable headers and the compiler version. With module retrieval disabled, it verifies the allowlisted cache, rebuilds the frozen cap-71 stock source with its original build flags, then verifies the cache again. The native stock ELF must equal `a23130f74210946291ed3609797e5b218ece5a7bd70df318851cf91e634da1e1` byte for byte and reproduce the retained build metadata. Only then does the driver publish the private SDK and module cache under the request-specific native toolchain directory. A failure before publication removes the disposable native build tree and leaves the controller logs.

On success, retain the native receipt, digest it and the emitted `toolchain-binding.json`, and include both digests in the canonical controller release. After a successful supply release, the controller may adopt the exact emitted binding at `requests/2026-11-25-slow-river-readiness.toolchain.json` for the original reservation. The binding names the unaltered proof request hash, absolute compiler path and executable digest, and the module-cache path. The original proof checks exact stock ELF equality again before building the readiness candidate. This supply request has zero workload arms and no timing authority.
